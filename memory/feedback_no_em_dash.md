Never use em dashes (—) in any content — written text, JSON data, playbook content, UI strings, or code comments.

**Why:** User preference, stated explicitly.

**How to apply:** Use a hyphen-minus (-), a colon, or restructure the sentence instead. Check all JSON data files and generated content for em dashes before committing.
